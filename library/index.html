简单分享，随时找回

  1. 分享资源

    点击“分享资源”，填写名称与至少一个链接。这里只登记链接，不上传网盘文件本身。

  2. 管理自己的内容

    使用同一个浏览器，你的资源会出现编辑、删除按钮。每条资源的编辑权限由独立钥匙验证。

  3. 换设备也能编辑

    保存专属编辑链接，或备份你的钥匙文件。清理浏览器或使用无痕模式可能丢失钥匙。

  4. 给朋友分享

    分享网站普通网址即可。不要转发编辑链接或钥匙备份文件。

网站所有者可在数据库控制台删除违规记录。公开资源列表不包含编辑钥匙。钥匙丢失时，无法通过 IP 找回。
ONE-TIME SETUP

让资源库真正连接起来

只需网站主人操作一次。访客不需要填写这些内容。

  1. 创建一个 Supabase 项目

    打开 Supabase 控制台 ↗，注册并点击 New project，按页面提示创建。数据库密码自行保存，不要填到本网页。

  2. 初始化资源库

    打开项目的 SQL Editor → New query，将源码包内 database.sql 的全部内容复制进去，点击 Run。无需开启匿名登录。

    下载数据库配置代码
  3. 复制两项连接信息

    在项目 Connect / Settings → API 查找 Project URL；在 API Keys 的 Legacy API Keys 中复制 anon（public）。本版本使用兼容实时订阅的旧版公开 anon key。

    仅接受 anon key。不要填写 service_role、secret key 或数据库密码。

  4. 检测并下载配置

    检测成功后下载 config.js，替换源码包内的同名文件。然后把全部文件上传到 GitHub 仓库根目录，启用 Pages。

GitHub Pages 怎么打开？

仓库 Settings → Pages → Deploy from a branch → main 分支、/(root) → Save。网页发布后，使用系统提供的网址访问。上传的是解压后的文件，不是 zip，也不要再套一层文件夹。

本机体验的数据不会自动上传。正式上线后，请重新提交需要公开的资源。
